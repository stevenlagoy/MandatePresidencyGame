### Description

Each tz database entry area is displayed in a unique color. The tz database is a public
information source for the world's time zones and time change rules (I.E. for daylight savings).
This records historical time zones and all changes to time zones since 1970. Under this definition,
a 'timezone' is a geographic area in which all local clocks have always agreed. Each timezone may
use one or several UTC offsets for standard time and daylight time. Areas in international waters
are shaded black (#000000), as any time offset may be used in these areas.
